# Правила фермы Nexcore

Ты — агент фермы. Каждый запуск ты берёшь ОДНУ задачу из `BACKLOG.md`, доводишь её
до рабочего состояния с зелёными тестами и пушишь. Пиши код и отчёты на русском
(комментарии в коде — по-русски или по-английски, как удобнее).

## Стек по умолчанию
- Python 3.12+, aiogram 3.x, SQLite (aiosqlite), pytest + pytest-asyncio
- Деплой: Railway, автодеплой из GitHub (каждый проект — отдельный сервис с Root Directory = `projects/<slug>`)
- Новый проект ВСЕГДА начинается с копии `templates/aiogram-bot/`

## Структура
```
projects/<slug>/        — один проект = одна папка, самодостаточная
reports/YYYY-MM-DD.md   — отчёт каждого запуска
BACKLOG.md              — очередь задач
```

## Жёсткие правила
1. **Одна задача за запуск.** Не начинай вторую, даже если время осталось — лучше доведи первую до блеска.
2. **Без зелёных тестов — не в main.** Красные тесты → коммит в ветку `wip/<slug>`, задача помечается `[!]` с причиной.
3. **Секреты никогда не коммитятся.** Только `.env.example` с пустыми значениями. Токены — через переменные Railway.
4. **Чужие репо не трогать.** NHLPROJECT, NHL-REVIVAL, WordFlash и другие боевые проекты — только если задача явно указывает репо, и тогда только через ветку + PR, никогда не пушить в их main.
5. **Никаких рандом-механик и ставок/прогнозов на деньги** в ботах, где принимаются платежи.
6. Не удаляй и не переписывай чужие проекты в `projects/` — только тот, над которым работаешь.
7. **Комп Эрика — только чтение.** Перед задачей ищи готовое (шаг 1.5 FARM_PROMPT.md). `Workspace/Secrets`, `Backups`, `Railway`, `.env` — не открывать никогда.
8. Если задача непонятна — не выдумывай: пометь `[?]` с вопросом в отчёте и возьми следующую.

## Определение «готово»
- `python -m pytest -q` в папке проекта — зелёный, минимум 5 осмысленных тестов (хендлеры, БД, бизнес-логика)
- `python -m scripts.smoke` (из шаблона) — бот собирается, все роутеры подключены, без сетевых вызовов
- `README.md` проекта: что делает, команды, переменные окружения, как задеплоить
- Код запускается командой из `Procfile` / `railway.json` без правок
- Папка `promo/` с промо-китом (см. шаг 6.5 в FARM_PROMPT.md)
