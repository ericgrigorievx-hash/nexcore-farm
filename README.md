# nexcore-farm

Ферма агентов Nexcore. Каждый день запланированная задача берёт верхнюю задачу из
`BACKLOG.md`, делает проект в `projects/<slug>/`, гоняет тесты и пушит в main
только при зелёных тестах. Отчёты — в `reports/`.

- `CLAUDE.md` — правила для агента
- `FARM_PROMPT.md` — шаги конвейера (меняешь этот файл → меняется поведение фермы)
- `BACKLOG.md` — очередь: пиши задачи одной строкой
- `templates/aiogram-bot/` — шаблон бота с офлайн-тестами (настоящий Dispatcher, подменённый Telegram API)
