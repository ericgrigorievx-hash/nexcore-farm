# Предложение для онлайн-школ (SAT)

**Что получаете:** готовые пакеты заданий SAT Math по 19 темам — для каждой темы PDF с заданиями по возрастанию сложности и PDF с ответами и разборами. Удобно раздавать преподавателям под темы учеников.

**Как подключить:** откройте бота {BOT_LINK} → /catalog → посмотрите превью нужных тем → «Запросить пакет». Для набора тем сразу на всю школу напишите нам — договоримся об условиях.

**Что дальше:** мы можем добавить в каталог темы под вашу программу (бот позволяет добавлять разделы и темы без доработки кода).
