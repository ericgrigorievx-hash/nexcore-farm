# Где искать аудиторию (репетиторы SAT Math)

1. **Каналы и чаты репетиторов по математике** — прямая ЦА, ищут материалы под учеников.
2. **Сообщества подготовки к SAT / поступления в зарубежные вузы** — там же сидят репетиторы и родители, которые ищут репетиторов.
3. **Чаты преподавателей международных программ (IB, A-Level, AP)** — пересекаются с SAT по математике.
4. **Каналы онлайн-школ, готовящих к SAT** — их преподавателям нужны задания по темам; возможен B2B.
5. **Каналы education-консультантов по поступлению в США** — рекомендуют репетиторов и материалы.
6. **Сообщества репетиторов-фрилансеров (биржи, чаты «ищу/предлагаю ученика»)** — практики, считающие своё время.
7. **Методические каналы для учителей математики** — часть ведёт SAT-учеников параллельно со школой.

Конкретные названия каналов в задаче не указаны — подбирает Эрик.
